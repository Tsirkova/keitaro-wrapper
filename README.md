# Adrobot — обёртка над Keitaro

Приложение на FastAPI для создания кампаний в Keitaro и редактирования офферов в существующих кампаниях. Интерфейс — одна HTML-страница. SQLAlchemy сохраняет локальный журнал успешных изменений; актуальные кампании и доли офферов хранятся в Keitaro.

## Требования

- Python 3.11+
- Ключ Keitaro Admin API с доступом к кампаниям, потокам, офферам, доменам, группам и источникам трафика
- Настроенные домен, группа кампаний и источник трафика в Keitaro

## Установка и запуск

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env  # Windows PowerShell: Copy-Item .env.example .env
```

В файле `.env` укажите `KEITARO_API_KEY` из раздела Keitaro **Профиль → API ключи** и замените `CAMPAIGN_PREFIX` на `test_<ваша_фамилия>_`, например `test_ivanov_`. Не добавляйте `.env` в Git и не передавайте ключ в браузер. По умолчанию используется SQLite в файле `adrobot.db`. Для PostgreSQL задайте соответствующий URL подключения SQLAlchemy в `DATABASE_URL` и установите драйвер этой базы.

Примените миграцию и запустите сервер:

```bash
alembic upgrade head
uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload
```

Откройте [приложение](http://127.0.0.1:8000). Интерактивная [документация API FastAPI](http://127.0.0.1:8000/docs) доступна по пути `/docs`.

## Как это работает

1. Форма создания загружает актуальные домены, группы, источники и офферы из Keitaro. Название кампании должно начинаться с настроенного префикса. Страна задаётся двухбуквенным ISO-кодом, например `AU`.
2. Приложение создаёт кампанию с ротацией потоков по позиции. Первый, обычный поток фильтрует посетителей по стране и перенаправляет их на Google. Второй, поток по умолчанию, направляет остальных посетителей на выбранный оффер. Если создание потока завершается ошибкой, приложение пытается архивировать незавершённую кампанию.
3. Редактор загружает кампанию и её потоки из Keitaro. Добавление, удаление и восстановление офферов сначала меняют черновик в браузере, как в демонстрационном видео. Удалённые офферы остаются видимыми с долей 0%. Долю оффера можно закрепить; оставшийся процент распределяется максимально равномерно между остальными офферами. Например, при закреплённых 25% два других оффера получат 38% и 37%. Кнопка **«Отправить в Keitaro»** сохраняет черновик одним запросом, **«Отменить»** — сбрасывает его. Сумма сохраняемых долей равна 100%. Удалить последний оффер нельзя. После сохранения интерфейс показывает данные, прочитанные из Keitaro. Если офферы или доли успели измениться, устаревший черновик отклоняется.

Запросы к Keitaro используют `/admin_api/v1` и заголовок `Api-Key`. Логин, пароль и ключ API не хранятся в репозитории. Указанная команда запуска делает приложение доступным только на локальном компьютере; для доступа нескольких пользователей необходимо добавить аутентификацию.

## Миграции и тесты

```bash
alembic upgrade head
alembic downgrade base
alembic upgrade head
pip install -r requirements-dev.txt
pytest -q
```

Миграция создаёт только локальную таблицу журнала `operations` и не изменяет базу данных Keitaro. Тесты используют подменный клиент Keitaro и не обращаются к реальному тестовому аккаунту.
